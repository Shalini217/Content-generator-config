FEATURES:
=========

✅ CHECKBOX LIST
   - Each content type has its own checkbox
   - Click anywhere on the row to toggle
   - Clear visual feedback

✅ PRODUCT FIELD SHOWN
   - Each checkbox shows the product field name below
   - Helps users understand what they're selecting

✅ VISUAL FEEDBACK
   - Unchecked: Light gray background
   - Hover: Blue highlight
   - Checked: Blue background stays

✅ SELECT ALL / DESELECT ALL
   - Quick action buttons at the top
   - Select all content types instantly
   - Deselect all to start fresh

✅ SELECTION SUMMARY
   - Shows selected count below checkboxes
   - Lists selected content types with their product fields
   - Real-time updates

✅ AUTO-LOADS ON PAGE OPEN
   - No file upload needed
   - Checkboxes appear instantly
   - Status: "✓ 7 content types available"

HOW TO USE:
===========

1. OPEN APP
   → Checkbox list automatically populated

2. SELECT CONTENT TYPES
   → Click checkboxes for desired types
   → OR click "Select All" button
   → See selection update below

3. CONTINUE
   → Upload taxonomy and brand voice
   → Click "Process & Continue"

4. CONFIGURE
   → Only selected types appear in Step 3
   → Product field auto-filled
   → Configure prompts and attributes

5. GENERATE & DOWNLOAD
   → Generate JSON
   → Download configuration

CHECKBOX BEHAVIOR:
==================

INDIVIDUAL SELECTION:
- Click checkbox to toggle
- Click anywhere on row to toggle
- Visual feedback on hover
- Blue highlight when selected

SELECT ALL BUTTON:
- Checks all checkboxes
- All content types selected
- Summary updates

DESELECT ALL BUTTON:
- Unchecks all checkboxes
- Selection cleared
- Summary updates

SELECTION SUMMARY:
- Shows count: "Selected Content Types (X)"
- Lists each selected type
- Shows product field mapping
- Updates in real-time
