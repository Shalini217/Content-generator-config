HOW TO UPDATE CONTENT TYPES DATA
==================================

The content types are now EMBEDDED directly in the HTML file for seamless operation.
No manual file loading required - the dropdown populates automatically!

HOW TO UPDATE WITH YOUR EXCEL DATA:
====================================

OPTION 1: Manual Update (Quick)
--------------------------------

1. Open content-config-generator.html in a text editor
2. Find the line: const CONTENT_TYPES_DATA = {
3. Replace the data with your content types from Excel
4. Save the file

Example:
If your Excel has:
| Content Type | Product Field Name |
|--------------|-------------------|
| newType      | newFieldName      |

Add this to CONTENT_TYPES_DATA:
"newType": {
    "productFieldName": "newFieldName"
},

OPTION 2: Read from Your Excel File
------------------------------------

If you have Content Types.xlsx in Downloads folder with your actual data,
you can convert it to the required format:

1. Open Content Types.xlsx
2. For each row, create an entry like this:

   Excel Row:
   Content Type: myContentType
   Product Field Name: myProductField

   Becomes:
   "myContentType": {
       "productFieldName": "myProductField"
   },

3. Copy all entries into CONTENT_TYPES_DATA in the HTML file

EXAMPLE CONVERSION:
===================

Excel File (Content Types.xlsx):
┌────────────────────┬──────────────────────────┐
│ Content Type       │ Product Field Name       │
├────────────────────┼──────────────────────────┤
│ title              │ gsaProductDetail         │
│ description        │ gsaProductDescription    │
│ bullets            │ gsaBulletPoints          │
│ seoTitle           │ seoPageTitle             │

-------------------------
const CONTENT_TYPES_DATA = {
    "title": {
        "productFieldName": "gsaProductDetail"
    },
    "description": {
        "productFieldName": "gsaProductDescription"
    },
    "bullets": {
        "productFieldName": "gsaBulletPoints"

    "seoTitle": {

    }
};

STEP-BY-STEP UPDATE GUIDE:
===========================

1. LOCATE THE DATA SECTION
   - Open: C:\Users\DELL\content-config-generator.html
   - Search for: "CONTENT_TYPES_DATA"
   - You'll find the const declaration around line 1331

2. UPDATE THE DATA
   - Between the { } braces, list all your content types
   - Format: "contentTypeName": { "productFieldName": "value" },
   - Don't forget commas between entries
   - NO comma after the last entry

3. SAVE THE FILE
   - Save content-config-generator.html
   - Close the editor

4. TEST
   - Open the HTML file in browser
   - Dropdown should show all your content types
   - Select types and proceed with configuration

TEMPLATE FOR ADDING NEW CONTENT TYPE:
======================================

"YOUR_CONTENT_TYPE_NAME": {
    "productFieldName": "YOUR_PRODUCT_FIELD_NAME"
},

Replace:
- YOUR_CONTENT_TYPE_NAME: The content type identifier (e.g., "title", "keywords")
- YOUR_PRODUCT_FIELD_NAME: Database field name (e.g., "gsaProductDetail")

VALIDATION:
===========

After updating, check:
1. ✓ Each entry has proper quotes around keys
2. ✓ Commas between entries (but NOT after last entry)
3. ✓ Curly braces are balanced { }
4. ✓ No syntax errors in JavaScript

Common Mistakes:
❌ Missing comma: "type1": {...} "type2": {...}  (missing comma between)
✅ Correct:      "type1": {...}, "type2": {...}

❌ Extra comma:  "type1": {...}, "type2": {...}, }  (comma after last item)
✅ Correct:      "type1": {...}, "type2": {...} }

❌ Missing quotes: {title: {...}}  (no quotes around 'title')
✅ Correct:       {"title": {...}}

BROWSER CONSOLE CHECK:
======================

To verify data loaded correctly:
1. Open browser (F12)
2. Go to Console tab
3. Type: CONTENT_TYPES_DATA
4. Press Enter
5. You should see all your content types listed

WHAT HAPPENS ON PAGE LOAD:
===========================

1. Browser loads HTML file
2. JavaScript reads CONTENT_TYPES_DATA constant
3. loadContentTypesFromSystem() function executes
4. Dropdown is populated with all content types
5. Status shows: "✓ X content types available"
6. User can immediately select from dropdown

NO file reading, NO manual loading, NO buttons - it just works!
