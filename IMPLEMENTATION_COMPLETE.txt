UPDATING CONTENT TYPES:
========================

To add/modify content types:

1. Open content-config-generator.html in text editor
2. Find: const CONTENT_TYPES_DATA = {
3. Add/modify entries:
   "newType": {
       "productFieldName": "newFieldName"
   },
4. Save file
5. Refresh browser - done!

See HOW_TO_UPDATE_CONTENT_TYPES.txt for detailed instructions.
