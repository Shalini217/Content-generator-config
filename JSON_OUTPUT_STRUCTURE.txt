KEY POINTS:
-----------
1. Excel Sheet Names → Categories (extracted automatically)
2. Row 6 in each sheet → Attributes for that category
3. Each Content Type gets ALL categories in its "categories" object
4. You can configure which attributes to use for each category within each content type
5. Each category can have different selected attributes for different content types

EXAMPLE USE CASE:
-----------------
For "title" content type:
  - Envelopes-and-mailers: Use ["type", "envelope_style", "brand"]
  - Office-decor: Use ["type", "frame_style", "color"]

For "gsaHighlights" content type:
  - Envelopes-and-mailers: Use ["material", "color", "features"]
  - Office-decor: Use ["dimensions", "features", "brand"]

This allows complete flexibility in attribute selection per category per content type!
