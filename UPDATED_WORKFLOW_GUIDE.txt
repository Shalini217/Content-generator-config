UPDATED WORKFLOW GUIDE - CONTENT TYPE SELECTION
================================================

MAJOR UPDATE: Content types are now SELECTABLE from the uploaded Excel file!

HOW IT WORKS NOW:
=================

STEP 1: Upload Content Types.xlsx
----------------------------------
1. Upload your Content Types.xlsx file
2. The file contains ALL available content types with their configurations
3. You will see a table with checkboxes showing all available content types

STEP 2: SELECT Content Types You Need
--------------------------------------
1. After upload, you see a checkbox table with all content types
2. Each row shows:
   ☑️ Checkbox | Content Type Name | Field Name | Product Field Name
3. Select ONLY the content types you want to configure
4. Use "Select All" or "Deselect All" buttons for convenience
5. Selected rows are highlighted in light blue
6. Counter shows: "X of Y content types selected"

STEP 3: Proceed to Configuration
---------------------------------
1. Only SELECTED content types appear in Step 3 configuration
2. Field Name and Product Field Name are AUTO-FILLED from Excel
3. You only configure prompts and select attributes

COMPLETE STEP-BY-STEP:
=======================

STEP 1: UPLOAD FILES
--------------------

1. Upload Taxonomy.xlsx
   ✓ Categories extracted from sheet names
   ✓ Attributes extracted from Row 6

2. Upload Brand Voice document
   ✓ Brand voice loaded

3. Upload Content Types.xlsx
   ✓ All content types loaded
   ✓ Shows checkbox table

4. SELECT Content Types:
   - Check the ones you want to configure
   - Uncheck the ones you don't need
   - Use Select All / Deselect All buttons
   - See selection counter update

5. (Optional) Upload FieldName.txt
   ✓ Enables dropdowns for field selection

6. Click "Process & Continue →"

STEP 2: REVIEW DATA
-------------------

1. Review extracted categories
2. Review attributes for each category
3. Click "Configure Settings →"

STEP 3: CONFIGURE
-----------------

1. Global Settings (Store ID, locale, etc.)

2. For Each SELECTED Content Type:
   - Configure prompts (Main, Prefix, Suffix)
   - Field Name: AUTO-FILLED ✓
   - Product Field Name: AUTO-FILLED ✓
   - Set other options (Min attrs, JSON, Strategy)
   - Select attributes for each category

3. Click "Generate JSON Configuration →"

STEP 4: DOWNLOAD
----------------

1. Review JSON (contains only selected content types)
2. Download configuration file
3. Done!

TIPS:
=====

1. MAINTAIN ONE MASTER FILE
   - Keep all possible content types in Content Types.xlsx
   - Select what you need each time
   - Easy to add new types later

2. START SMALL
   - First time: Select 1-2 content types
   - Test and verify JSON output
   - Then add more types

3. USE DESCRIPTIVE NAMES
   - In Excel, use clear content type names
   - Easier to identify and select

4. REVIEW BEFORE PROCEEDING
   - Check selection counter
   - Verify highlighted rows
   - Ensure you selected what you need

5. CHANGE ANYTIME
   - You can go back to Step 1
   - Change selection
   - Re-process without re-uploading files

This new selection system makes the workflow much more flexible and efficient!
